# BNP TruckPacker downloads

Installers for BNP TruckPacker, Brown Note Productions' truck pack planner.

Open the newest release under **Releases** on the right and download:

- **Windows:** `BNP-TruckPacker-Setup-<version>.exe`
- **Mac:** `BNP TruckPacker-<version>-universal.dmg`

Once installed, the app updates itself. This repo holds only the installers; the code is private.
